# Work in progress 🚧

Skills in this folder are **built in public** — unfinished on purpose.

- They may be rough, incomplete, or change shape without notice.
- Each should ship with a short `ROADMAP.md` describing what's left.
- Their status in the catalog is `wip` (derived from this folder).

When a skill is ready, move it into a real category and regenerate the catalog:

```bash
git mv skills/work-in-progress/<slug> skills/<category>/<slug>
npm run build:catalog
```

Got feedback on something here? That's the whole point — open an issue.
